# Task-Manager

**Task Manager** — *это простое консольное приложение на Python для управления повседневными задачами*. Оно позволяет добавлять, удалять, просматривать задачи и отмечать их как выполненные. Цель проекта — помочь пользователю организовать свои дела и ничего не забывать.
## Возможности программы

* Добавление задач.

* Удаление задач.

* Просмотр списка задач.

* Отметка выполненных задач.

## Планы на будущее

* Сохранение задач в файл.

* Добавление дедлайнов.

* Создание графического интерфейса.
